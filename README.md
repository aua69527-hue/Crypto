# MarketOps — غرفة عمليات الكريبتو

نسخة مصدر مستقلة قابلة للتشغيل للوحة العربية التي أعددناها. تتضمن واجهة React RTL، خادم Express، بيانات Binance العامة وقائمة مشاريع CoinGecko، وتحليل FVG/بنية السوق على 4 ساعات/ساعة/5 دقائق. أضفنا غلاف تشغيل قياسياً لأن ملفات التشغيل الأصلية كانت مرتبطة بقالب Manus.

## ما تحتاجه

Node.js 22.13 أو أحدث وpnpm 11.25. لا تحتاج مفاتيح Binance؛ التطبيق يقرأ البيانات العامة فقط. لا توجد أوامر تداول أو مفاتيح تداول/سحب، وDiscord غير مربوط في هذه النسخة.

## تشغيل محلي

من مجلد المشروع:

```bash
corepack enable
pnpm install
pnpm dev
```

افتح `http://localhost:3000`. لفحص الأنواع وبناء ملفات الواجهة استخدم `pnpm build`. لتشغيل ملفات الإنتاج محلياً بعد البناء استخدم `pnpm start`.

## رفع المصدر إلى GitHub يدوياً

أنشئ مستودعاً **خاصاً وفارغاً** من GitHub (من دون README أو License بالبداية). ثم من هذا المجلد نفّذ:

```bash
git init -b main
git add .
git status
git commit -m "Initial MarketOps dashboard"
git remote add github https://github.com/USERNAME/REPOSITORY.git
git push -u github main
```

بدّل `USERNAME` و`REPOSITORY`. راجع `git status` قبل commit؛ `.gitignore` يمنع عادةً ملفات `.env` و`node_modules` و`dist`. لا تضف أي مفاتيح أو Webhook إلى المستودع.

## النشر على الإنترنت

GitHub يحفظ الكود، لكنه لا يشغّل خادم Express. اختر استضافة تدعم Node.js أو Docker، واضبطها لتشغيل `pnpm build` ثم `pnpm start` أو لبناء `Dockerfile`. لا يكفي GitHub Pages لهذه النسخة لأن نقاط `/api/market/*` تحتاج خادماً. لا يوجد نشر تلقائي مفعّل.

## حدود التحليل

فلترة القائمة تستخدم حجم تداول 24 ساعة (10 ملايين دولار للفوري و25 مليوناً للعقود) ورتبة CoinGecko حتى 200 وقيمة سوقية دنيا 250 مليون دولار، وقد يظهر أقل من 50 زوجاً إذا لم تستوفِ الأصول الشروط. هذه المقاييس لا تثبت عمق دفتر الأوامر أو موثوقية المشروع. تحليل FVG مبسط للتوضيح والمراجعة البشرية، ولا يضمن نجاحاً أو ربحاً.
